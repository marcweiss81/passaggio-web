Download

Passaggio installs from a file (an APK) on GitHub, not Google Play. Installing over an older version keeps your progress.

You need an Android phone and headphones (wired or Bluetooth). The trainer's voice, sung examples and piano are built in, so nothing streams.

How to install

1

Tap the download button on your phone.

2

Open the file. If asked, allow installs from unknown apps, then tap Install.

3

Put on headphones, open Passaggio and follow the voice setup. Allow the microphone; it's the only permission the app asks for.

Play Protect may warn about an unknown developer, because the app isn't on Google Play. Only install a file you downloaded from this page or from the GitHub link above. If it came from there, tap Install anyway.

Check the file (optional)

Each APK on GitHub lists its SHA-256 code. On a computer, run sha256sum passaggio-candidate-*.apk (on Windows, certutil -hashfile … SHA256) and check the two match.
