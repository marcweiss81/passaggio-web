Privacy

Your voice stays with you.

The whole point of running the analysis on the phone is that nothing has to be sent anywhere.

The app

  • Passaggio has no account, no sign-in and no cloud backend.
  • The release build declares no internet permission. The only permission it asks for is the microphone, and only while a screen that listens is open.
  • Pitch and tone analysis, the trained models, song separation and lyric recognition all run on the device.
  • Your voice setup, lesson results, weak-area ledger, songs and settings are stored in an encrypted SQLite database whose key lives in the Android keystore. "Reset progress" clears it.
  • Recordings are not kept unless you turn on Save my singing to improve the trainer, and then they stay on the phone only.
  • Uninstalling the app removes all of it.

This website

  • This site is static. It does not record audio, assess singing or use cookies.
  • The Download page asks GitHub's public API for the newest release so it can show the current file name and size. That request goes to GitHub and is subject to GitHub's privacy statement. Fonts are loaded from Google Fonts.
  • The hosting provider records ordinary server logs (IP address, pages requested) as any website host does.
